## Donate Website Overview

-  A **nonprofit platform** focused on collecting donations for the underprivileged and vulnerable communities in Bangladesh.
- Built with **Tailwind CSS**, ensuring a responsive and user-friendly interface across all devices.
- Features include an **easy donation system**, **event updates**, and a **transparent reporting system** for donors.
## Technology 
- Javascript
- HTML-5
- Tailwind CSS
